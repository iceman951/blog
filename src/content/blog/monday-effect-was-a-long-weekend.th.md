สวัสดีครับ คราวนี้เปลี่ยนแนวไปทางการเงิน แต่เป็นความผิดพลาดแบบเดิมเป๊ะกับที่เคยเจอในบทความ benchmark

ถ้าเราซื้อหุ้นตัวเดิมจำนวนเงินเท่ากันทุกสัปดาห์ ยังไงก็ต้องเลือกสักวัน แล้วมักมีคนแนะนำวันจันทร์โดยอ้าง anomaly ในตำราการเงินที่เรียกว่า weekend effect ผมเลยลองรัน regression บนข้อมูลรายวันสิบปีของหุ้น 8 ตัวที่คนดูกันจริง โดยตั้งใจจะเขียนโพสต์สั้น ๆ ว่า effect นี้ตายไปนานแล้ว

ผลไม่ได้ออกมาแบบนั้นครับ รอบแรกเจอรูปแบบที่รอด permutation test ที่ family-wise p = 0.0005 รอบสองผมถึงรู้ว่ารูปแบบนั้นคืออะไร และมันไม่ใช่ anomaly ของตลาด **มันคือปฏิทิน**

**ทั้งหมดนี้ไม่ใช่คำแนะนำการลงทุน** ผมไม่ใช่ที่ปรึกษาการลงทุนที่มีใบอนุญาต และข้อสรุปข้างล่างคือการเลือกวันแทบไม่มีผลอยู่แล้ว

## สรุปก่อน เผื่อยังไม่อยากอ่านยาว

- ค่าเฉลี่ยดิบ **วันจันทร์เป็นวันที่ดีที่สุด**ของหุ้นส่วนใหญ่ ซึ่งตรงข้ามกับ weekend effect ในตำรา
- permutation test ที่รักษาความสัมพันธ์ระหว่างหุ้นไว้ ให้ family-wise **p = 0.0005** ดูเหมือนเจอของจริง
- แต่ผลตอบแทน "หนึ่งวันทำการ" ของวันจันทร์กินเวลาเฉลี่ย **3.04 วันปฏิทิน** ส่วนวันอื่นราว 1.0
- พอคุมจำนวนวันปฏิทิน TSLA จาก p=0.002 เป็น 0.120, AMD จาก 0.064 เป็น 0.790, max|t| ลดจาก 3.96 เหลือ 2.72
- **ไม่ได้เกิดจากวันสุดขั้วไม่กี่วัน** (winsorize แล้วแทบไม่ขยับ) แต่**ไม่ทำซ้ำ** — ครึ่งแรกกับครึ่งหลังของทศวรรษ ตัวที่มีนัยสำคัญคนละตัวกัน
- DCA จริง: การเลือกวันมีผลน้อยกว่าการบังเอิญเริ่มคนละสัปดาห์ **8–26 เท่า**

## วัดอะไรบ้าง

หุ้น 8 ตัว — NVDA, TSLA, AAPL, MSFT, AMZN, META, GOOGL, AMD — **2,512 วันทำการ** ตั้งแต่ 14 ก.ย. 2016 ถึง 11 ก.ย. 2026 ใช้ราคาปิดที่ปรับ split แล้วจาก public historical endpoint ของ Nasdaq ส่วน market ใช้ระดับดัชนี S&P 500 จาก FRED

สมการเป็นแบบมาตรฐาน ใช้ log return รายวัน และให้วันจันทร์เป็นฐาน:

```
r_t = α + β·r_market,t + γ_Tue·D_Tue + γ_Wed·D_Wed + γ_Thu·D_Thu + γ_Fri·D_Fri + ε_t
```

γ แต่ละตัวตอบว่า "หุ้นตัวนี้ให้ผลตอบแทนในวันนั้นมากหรือน้อยกว่าวันจันทร์เท่าไหร่ หลังหักสิ่งที่ตลาดทำในวันเดียวกันออกไปแล้ว" ค่า standard error ใช้ Newey-West เพราะผลตอบแทนรายวันมี heteroskedasticity และ autocorrelation อ่อน ๆ ถ้าใช้ค่ามาตรฐานธรรมดาจะอ้างความแม่นยำเกินกว่าที่ข้อมูลมี

## รอบแรกดูแรงมาก

ค่าเฉลี่ยแบบไม่คุมอะไรเลย วันจันทร์เป็นวัน*ที่ดีที่สุด*ของหุ้นส่วนใหญ่:

| | จันทร์ | อังคาร | พุธ | พฤหัส | ศุกร์ |
| --- | ---: | ---: | ---: | ---: | ---: |
| NVDA | 30.8 | 21.8 | 30.0 | 19.6 | −2.4 |
| TSLA | 66.9 | 18.7 | 20.9 | −33.3 | −3.3 |
| AMD | 56.3 | 15.4 | 21.5 | −3.6 | 2.7 |
| AAPL | 19.0 | 16.8 | 21.1 | −7.4 | 0.7 |

<p class="affiliate-note">ค่าเฉลี่ย log return หน่วยเป็น basis point ต่อวันทำการ</p>

พอคุม market แล้ว TSLA ปฏิเสธสมมติฐานว่าทุกวันเท่ากับวันจันทร์ที่ χ²(4) = 17.6, p = 0.002 ส่วน AAPL ที่ p = 0.021 และมี 9 จาก 32 ค่าสัมประสิทธิ์ที่ได้ p < 0.05

การอ่านแบบง่าย ๆ คือ 9 ครั้งเทียบกับ "คาดว่าเจอโดยบังเอิญ ~1.6 ครั้ง" แปลว่ามีสัญญาณจริง — **ซึ่งผิด** และผิดด้วยเหตุผลที่ไม่ค่อยมีใครพูดถึง: Bonferroni ตั้งอยู่บนสมมติฐานว่าการทดสอบเป็นอิสระต่อกัน แต่หุ้นแปดตัวนี้เคลื่อนไหวไปด้วยกัน ต่อให้หัก market beta ออกแล้ว residual ก็ยังมี technology factor ร่วมกันอยู่ เลขคณิตเรื่อง multiplicity จึงใช้ไม่ได้

ผมเลยสร้าง null ขึ้นมาจากข้อมูลเองแทน: สลับป้ายวันในปฏิทิน แล้ว**ใช้ปฏิทินที่สลับแล้วชุดเดียวกันกับหุ้นทั้งแปดตัว** เพื่อให้ความสัมพันธ์ระหว่างหุ้นยังอยู่ครบ จากนั้น fit ใหม่ทั้งหมด บันทึกค่า |t| ที่ใหญ่ที่สุดในบรรดา 32 ค่า แล้วทำซ้ำ 2,000 รอบ:

| | max &#124;t&#124; |
| --- | ---: |
| ที่สังเกตได้จริง | 4.21 |
| null median | 2.20 |
| null เปอร์เซ็นไทล์ที่ 95 | 3.09 |
| null เปอร์เซ็นไทล์ที่ 99 | 3.48 |

family-wise p = **0.0005** มีบางอย่างในโครงสร้างวันที่ไม่ได้เกิดจากความบังเอิญ

## แล้วผมก็ถามว่าวันจันทร์ยาวแค่ไหน

ผลตอบแทนวันจันทร์ของหุ้น คือราคาปิดวันจันทร์หารด้วยราคาปิดวันศุกร์ **มันคร่อมวันหยุดสุดสัปดาห์** ขณะที่ผลตอบแทนของวันอื่นคร่อมแค่หนึ่งคืน

```
จันทร์ 3.04 วันปฏิทิน     อังคาร 1.30     พุธ 1.01     พฤหัส 1.01     ศุกร์ 1.03
```

อังคารได้ 1.30 ไม่ใช่ 1.00 เพราะวันหยุดที่ตรงกับวันจันทร์ดันช่องว่างไปโผล่ที่วันอังคาร ดังนั้น "ผลตอบแทนเฉลี่ยต่อวันทำการ แยกตามวัน" คือการเอาช่วงเวลาสามวันไปเทียบกับช่วงเวลาหนึ่งวัน ถ้าหุ้นมี drift ไปตามเวลาปฏิทินแม้แต่น้อย วันจันทร์ก็ต้องสูงกว่าโดยกลไก และนั่นไม่ใช่ anomaly ของตลาด **มันคือหน่วยที่เทียบกันไม่ได้**

ใส่ตัวแปรควบคุมแค่ตัวเดียว คือจำนวนวันปฏิทินที่ผ่านไปตั้งแต่ราคาปิดครั้งก่อน ก็พอทดสอบได้:

| Wald p | base | คุมวันปฏิทิน | winsorize 1% | ครึ่งแรก | ครึ่งหลัง |
| --- | ---: | ---: | ---: | ---: | ---: |
| NVDA | 0.213 | 0.248 | 0.074 | 0.823 | **0.022** |
| TSLA | **0.002** | 0.120 | **0.001** | **0.004** | 0.070 |
| AAPL | **0.021** | **0.004** | **0.034** | **0.001** | 0.387 |
| MSFT | 0.486 | 0.619 | 0.530 | 0.386 | 0.806 |
| AMZN | 0.316 | 0.160 | 0.090 | **0.000** | 0.792 |
| META | 0.512 | 0.388 | 0.271 | 0.426 | 0.962 |
| GOOGL | 0.906 | 0.391 | 0.737 | 0.310 | 0.995 |
| AMD | 0.064 | 0.790 | **0.049** | 0.159 | 0.664 |

TSLA จาก 0.002 กลายเป็น 0.120 ส่วน AMD จาก 0.064 กลายเป็น 0.790 ค่าสัมประสิทธิ์ส่วนใหญ่พลิกเครื่องหมาย และ max|t| ของทั้งชุดลดจาก 3.96 เหลือ 2.72 — ผลที่แรงที่สุดในงานนี้ ส่วนใหญ่คือประโยคที่บอกว่าวันหยุดสุดสัปดาห์ยาวกว่าคืนวันธรรมดา

อีกสองข้อที่ต้องเช็ค เพราะคำว่า "มันคือวันหยุด" เองก็เป็นข้ออ้างที่ขี้เกียจได้เหมือนกัน:

**ไม่ได้เกิดจากวันใหญ่ ๆ ไม่กี่วัน** — winsorize ผลตอบแทนที่เปอร์เซ็นไทล์ 1 และ 99 แล้วแทบไม่ขยับ TSLA ยังอยู่ที่ p = 0.001 อะไรก็ตามที่เป็นอยู่ มันกระจายทั่วกลุ่มตัวอย่าง ไม่ได้ถูกแบกด้วยวันประกาศงบสี่ห้าวัน

**มันไม่ทำซ้ำ** — ตัดทศวรรษเป็นสองครึ่ง ตัวที่มีนัยสำคัญเปลี่ยนหน้า AAPL เป็น p = 0.001 ในครึ่งแรก แล้วเป็น 0.387 ในครึ่งหลัง AMZN จาก 0.000 ไป 0.792 ส่วน NVDA กลับทาง 0.823 แล้วเป็น 0.022 ครึ่งแรกมีนัยสำคัญ 3 จาก 8 ครึ่งหลังเหลือ 1 จาก 8 และไม่ใช่ตัวเดียวกัน — calendar effect ที่เสถียรจริงไม่ควรมีพฤติกรรมแบบนี้

AAPL เป็นตัวเดียวที่แข็งขึ้นหลังคุมปฏิทินและยังอยู่ในครึ่งแรกด้วย ผมจะไม่สร้างเรื่องเล่ารอบหุ้นตัวเดียวที่รอดจากแปดตัว หลังจากหั่นกลุ่มตัวอย่างมาหลายรอบขนาดนี้ครับ — นั่นคือวิธีที่คนเราหลอกตัวเองให้เชื่อว่าเจอของ

## แล้วมันมีค่าแค่ไหนกับการ DCA จริง

คำถามเชิงสถิติกับคำถามเชิงปฏิบัติเป็นคนละคำถาม ผมเลยจำลองคำถามหลังตรง ๆ: ลงทุน $100 ทุกสัปดาห์เป็นเวลาสิบปี ในวันเดิมเสมอ แล้วเทียบมูลค่าปลายทางของทั้งห้าตาราง

| | เลือกวัน | สัปดาห์ที่เริ่ม | เท่าตัว |
| --- | ---: | ---: | ---: |
| NVDA | 25.1 | 649.0 | 26× |
| AMD | 22.9 | 379.5 | 17× |
| TSLA | 14.3 | 148.6 | 10× |
| AAPL | 4.4 | 66.5 | 15× |
| AMZN | 3.0 | 37.9 | 13× |
| META | 2.5 | 21.0 | 8× |
| MSFT | 2.2 | 51.7 | 23× |
| GOOGL | 2.2 | 42.5 | 20× |

<p class="affiliate-note">ช่วงห่างระหว่างผลดีที่สุดกับแย่ที่สุด หน่วยเป็นจุดของผลตอบแทนรวม คอลัมน์ "เลือกวัน" เปลี่ยนวันแต่ตรึงจุดเริ่ม ส่วน "สัปดาห์ที่เริ่ม" ตรึงวัน (วันพุธ) แล้วเปลี่ยนว่าเริ่มสัปดาห์ไหนใน 52 สัปดาห์แรก</p>

วันที่ดีที่สุดชนะวันที่แย่ที่สุดอยู่ 2.2 จุดบน MSFT จากผลตอบแทนรวมราว 192 จุด ขณะที่การเริ่มแผนเดียวกันเร็วหรือช้าไปไม่กี่สัปดาห์ ทำให้ผลต่างกันถึง 52 จุด **ทั้งแปดตัว จังหวะที่เริ่มมีผลมากกว่าการเลือกวัน 8 ถึง 26 เท่า** และการเลือกหุ้นมีผลมากกว่าทั้งสองอย่างมหาศาล เพราะ NVDA ให้ผลตอบแทนราว 2,370% เทียบกับ MSFT ที่ 192%

คำตอบของคำถามตั้งต้นจึงเป็น: **ไม่มีวันไหนดีกว่าอย่างเชื่อถือได้** สัญญาณที่ใหญ่ที่สุดส่วนใหญ่มาจากหน่วยที่เทียบกันไม่ได้ มันไม่ทำซ้ำนอกกลุ่มตัวอย่าง และต่อให้เชื่อตามหน้าตาที่เห็น มันก็ยังเล็กกว่าความบังเอิญเรื่องวันเริ่มต้นเป็นสิบเท่า

## สิ่งที่งานนี้ยืนยันไม่ได้

- **กลุ่มตัวอย่างคือผู้รอดชีวิต** ผมเลือกบริษัทแปดแห่งที่ดังในปี 2026 ทุกตัวเป็นผู้ชนะรายใหญ่ที่ถูกเลือกหลังจากรู้ผลแล้ว ซึ่งบิดเบือนระดับผลตอบแทนอย่างรุนแรง และผมตัดไม่ได้ว่ามันไม่ได้ไปกำหนดโครงสร้างรายวันด้วย
- **ราคาปรับ split แต่ไม่ได้ปรับปันผล** สำหรับ AAPL กับ MSFT คือหายไปราวครึ่งเปอร์เซ็นต์ต่อปี และถ้าวัน ex-dividend กระจุกอยู่บางวันในสัปดาห์ มันจะไปลงที่สัมประสิทธิ์ตัวใดตัวหนึ่งแทนที่จะกระจาย
- **ดัชนี market ไม่รวมปันผล** เพราะเป็นระดับดัชนี ไม่ใช่ total return index
- **ตลาดเดียว ทศวรรษเดียว อุตสาหกรรมเดียว** นี่คือหุ้นเทคสหรัฐแปดตัว ในทศวรรษที่ใจดีกับหุ้นเทคสหรัฐมาก
- **permutation null สลับป้าย ไม่ได้สลับเป็นบล็อก** มันรักษาการกระจายตัวของผลตอบแทนและความสัมพันธ์ระหว่างหุ้นไว้ แต่ไม่ได้รักษา volatility clustering ภายในสัปดาห์
